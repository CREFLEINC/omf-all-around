# omf-all-around

OMF MES 통합 이슈 관리 저장소. 서버·클라이언트에 걸친 이슈를 이 저장소의 GitHub Issues로 관리한다.

## 하위 개발 프로젝트

이 폴더 아래에 두 제품 저장소를 clone해 쓴다. 각 저장소는 이 저장소에서 추적하지 않는다.

| 폴더 | 저장소 | 내용 |
|---|---|---|
| `omf-mes-server/` | `CREFLEINC/omf-mes-server` | 백엔드 API (NestJS · Prisma · PostgreSQL) |
| `omf-mes-client/` | `CREFLEINC/omf-mes-client` | 관리웹 · POP(Electron) · 모바일(Capacitor) 클라이언트 모노레포 |

공유 저장소: `git@github.com:CREFLEINC/omf-all-around.git`
