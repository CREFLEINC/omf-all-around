# 작업 완료 보고 양식

> 3차 통합 작업에서는 저장소 루트 기준 `docs/client-dev-workflow/integration.md`를 먼저 읽는다. 아래 종전 운영 절차는 통합 모드에 적용하지 않으며 기술 참고와 이전 업무 이력으로 보존한다.

```md
작업 완료 보고

- PR: <링크>
- 담당 팀: Agent : T<번호>
- 적용한 설계 기준: <커밋 포인터>
- 검증 수준: <중요 | 보통 | 낮음>
- 검증: <실행한 명령과 결과>
- 미실행 검증: <없음 | 항목과 이유>
- 기존 실패: <없음 | 이번 변경과 무관한 기존 실패>
- 설계 요청: <없음 | 사용자 경유 요청의 추적 이슈 번호>
```

공개 이슈에는 비공개 설계 본문, 실제 고객 데이터, 인프라 정보를 적지 않는다.
