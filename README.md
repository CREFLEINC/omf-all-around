# OMF 파이널 루틴

클라이언트 동작을 정본으로 서버와 빠르게 정합을 맞추는 통합 개발 환경이다.

1. [파이널 루틴 인계](OMF_ALL_ROUNDER_WORKFLOW.md)를 읽는다.
2. 클라이언트·서버를 clone하고 [복원 묶음 적용](portable-setup/README.md)을 진행한다.
3. 새 PC 환경과 대상 서버를 확인한 뒤 시나리오를 준비한다.

공유 대상은 공통 지침·양식·검토된 하네스 복사본이다. `.gitignore` 허용 목록 밖의 비밀정보·DB·증거·빌드 결과·기존 세션 기록은 포함하지 않는다. 로컬에만 있는 제품 커밋은 이 묶음과 별도로 이전한다.

공유 저장소: `git@github.com:CREFLEINC/omf-all-around.git`
