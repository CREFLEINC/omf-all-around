# 사용자 전달용 설계 요청서 양식

> 3차 통합 작업에서는 저장소 루트 기준 `docs/client-dev-workflow/integration.md`를 먼저 읽는다. 아래 종전 운영 절차는 통합 모드에 적용하지 않으며 기술 참고와 이전 업무 이력으로 보존한다.

이 문서는 사용자에게 전달을 부탁하기 위한 로컬 산출물이다. 비공개 설계 내용이 포함될 수 있으므로 공개 저장소에 커밋하지 않는다.

```md
# <정보 요청 | 설계 개선>

## 요청 팀

클라이언트 개발 <번호>팀

## 기준

- 고정 설계 커밋: <전체 커밋>
- 관련 자료: <경로와 버전>
- 관련 클라이언트 이슈: <번호>

## 확인한 사실

<오류·누락·불일치 또는 개선 필요 지점>

## 제품 영향

<현재 설계로 진행했을 때의 영향과 요청이 해결하는 요구사항>

## 요청 내용

<필요한 정보 또는 설계 개선을 구체적으로 작성>

## 회신 전 진행 계획

<기존 고정 설계를 기준으로 계속 진행할 업무와 보류할 최소 범위>
```
