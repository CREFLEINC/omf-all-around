# 파이널 루틴 모델 배정

사용자가 작업별 효율적 모델 선택을 위임했다. 2026-09-11 현재 이 세션의 도구에 노출된 모델 ID를 사용한다. 실제 모델 선택은 담당 생성/다음 지시를 보낼 때 지정하며, 이 문서 자체가 모델을 변경하지는 않는다.

| 업무 | 기본 모델 | 추론 |
|---|---|---|
| 시나리오·데이터 흐름·복잡한 정합 판단 | gpt-6-astra | high |
| 일반 클라이언트·서버 개발·원인 조사 | gpt-5.6-terra | medium |
| 정해진 관리자 웹/API 테스트 실행·증거 정리·아주 작은 수정 | gpt-5.6-luna | low, 화면 판단 시 medium |
| 해결이 어려운 복합 구현 | gpt-5.6-sol | high |

공식 모델 설명: https://learn.chatgpt.com/docs/models?surface=app
배정표는 이 프로젝트를 위한 초기 운영 판단이며 동일 품질이나 일정 비율의 비용 절감을 보장하는 벤치마크가 아니다.

- 개발 담당 세션은 유지하고 다음 작업 성격에 맞춰 모델을 지정한다. 장시간 도구 대기를 위해 고비용 에이전트를 별도 추가하지 않는다.
- 실행 에이전트는 명세·코드 수정 없이 실제 실행/결과 보고만 수행한다. 제품 오류는 개발 담당에게 넘기고, 절차 해석이나 조작 한계는 상위 모델로 전환한다.
- 단기 에이전트를 별도로 쓸 때는 지침 경로, cwd, 시나리오/버전, 시작 상태, 데이터 변수, 기대 결과, 중단 조건, 증거 경로를 전달한다. 부모 전체 대화를 무조건 복제하지 않는다.
- 실행 담당은 관리자 웹을 실제 조작할 수 있는 도구와 로컬 증거 저장 수단이 있는지 먼저 확인한다. 단순 API 실행으로 관리자 웹 검증을 대체하지 않는다.
- 동일 브라우저/테스트 데이터는 한 실행자만 조작한다. 수정·재시작과 실행을 조정한다.
- 작업 기록에 실제 지정한 모델·추론 수준·전환 사유를 남긴다. 가격/토큰 수를 추측해 비용 절감을 보고하지 않는다.
- 아직 담당 세션을 생성하거나 실행 모델을 바꾸지 않았다. 첫 배정부터 적용한다.
