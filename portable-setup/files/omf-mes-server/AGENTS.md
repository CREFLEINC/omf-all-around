# OMF 서버 Codex 지침

먼저 docs/agents/integration.md를 읽고 3차 통합 모드로 작업한다. 그다음 CLAUDE.md의 기술·도메인 지침을 읽는다. 기존 팀 워크플로의 운영 절차는 통합 지침으로 대체한다.

현재 계획은 파이널 루틴이다. 클라이언트 동작이 정본이며 서버를 맞춘다. 실제 화면을 직접 조작해 검증하고 검증 비용은 평균적인 개발 수준으로 제한한다.

시나리오는 관리자 웹·POP·모바일 전체 흐름이다. 화면 직접 조작과 캡처는 관리자 웹만 수행하고 POP·모바일 단계는 클라이언트 요청에 맞춘 실제 API 호출·요청/응답 증거로 대신한다. POP·모바일 UI/장치 검증 완료로 보고하지 않는다.

선행 계약 변경은 docs/계약-선행-수정항목.md에 즉시 기록하고 P-ID를 완료 보고·PR에 명시한다. contracts/*.json 직접 수정은 금지하며 공식 사본 갱신만 허용한다. 공유 장부는 제품 문서이므로 하네스 제외 대상이 아니다. 상세 절차는 docs/agents/integration.md를 따른다.
